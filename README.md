# 🚕 Ola Bookings Data Analysis Dashboard

## 📌 Project Summary
This project analyzes **Ola ride booking data** to identify patterns in customer bookings, ride cancellations, revenue generation, and payment behavior.

An **interactive Power BI dashboard** was developed to transform raw ride data into meaningful insights that help businesses make **data-driven decisions**.

The dataset contains **100,000+ ride records**, which were extracted, cleaned, and processed using **SQL and Excel**, followed by visualization and dashboard creation in **Power BI**.

---

## 🎯 Project Objectives

- Analyze ride booking trends across different time periods  
- Identify cancellation patterns by customers and drivers  
- Understand revenue generation and ride demand  
- Evaluate customer booking behavior  
- Generate insights to improve operational efficiency

## 🔄 Data Analysis Workflow

### 1️⃣ Data Extraction
- Imported ride booking dataset containing **100K+ records**
- Extracted key attributes including booking date, ride status, payment method, ride category, and revenue

### 2️⃣ Data Cleaning
- Removed duplicate records  
- Handled missing values  
- Standardized date formats and categorical fields  

### 3️⃣ Data Transformation
- Created calculated columns and KPIs  
- Structured the dataset for analytical reporting  

### 4️⃣ Dashboard Development
- Built an **interactive Power BI dashboard**
- Implemented slicers and filters for dynamic analysis
- Designed visualizations to track booking trends and performance metrics
